How the app is built

Six patterns, one booking flow

Each pattern below solves a specific problem this app would otherwise have. The code is the real code running above — open the dispatch console and you can watch each one announce itself as you click.

Real-world problems

What riders on Uber, Ola and Rapido complain aboutand how this app answers it

Three complaints keep coming up in consumer surveys, regulator notices and the 2025 Motor Vehicle Aggregator Guidelines. Each fix below is built on a pattern, which is why it took so little code — and each can be triggered from the Simulate real-world problems buttons above.

1 · Drivers cancel after accepting — State

A LocalCircles survey found 84% of app-cab users had been pushed into cancelling, so the rider paid the fee. Here a driver cancel sends the ride into a new RematchingState: same fare, a different driver, Rs.0 for the rider and a penalty for the driver. Riders can also cancel with "the driver asked me to" at no cost. Every other cancellation fee is 10% of the fare, capped at Rs.100, as the guidelines set.

2 · Fares you cannot trust — Decorator

Festival surges of 3x-4x, charges missing from the quote, and an alleged (and denied) iPhone-vs-Android price gap. Every pricing rule is wrapped by FairInputGuard (the device never reaches the rule) and SurgeCapGuard (at most 2x, never below 50%). The upfront quote is what is charged — even after a detour.

3 · Safety during the trip — Observer

The NCW's 2026 guidelines ask for route-deviation alerts and checks on long stops. SafetyMonitorObserver is a fifth subscriber to the driver's GPS: it raises "Are you okay?" after 3 minutes stood still or 0.8 km off the route, with an SOS that sends the car details and live location. Nothing else in the app changed to add it.

Factoryjs/patterns/factory.js

        
One class owns object creation. Callers name what they want;
           they never learn how it is built.

        

          Where it runs
          
Every vehicle tile in the picker was produced by
             VehicleFactory.available(), and booking calls
             VehicleFactory.create("SUV").

        

        

          What it replaces
          
A chain of if (type === "BIKE") new Bike() repeated in
             every screen that needs a vehicle.

        

        

          See it live
          
Click a different vehicle. The console prints the exact class the
             factory built and the fare rates it carries.

        

      

      

        
factory.js — abstract product, concrete products, factory

        

      

    


    
    

      

        Behavioural
        
Strategyjs/patterns/strategy.js

        
Interchangeable algorithms behind one method. The object using them
           can be handed a different one while the program is running.

        

          Where it runs
          
The pricing dropdown. FareCalculator holds one
             FareStrategy and asks it to calculate().

        

        

          What it replaces
          
A single calculateFare() that grows a new
             if branch for every festival offer and never shrinks.

        

        

          See it live
          
Switch to Surge pricing. Same trip, same vehicle — the
             receipt rebuilds itself with different line items, and no calling code changed.

        

      

      

        
strategy.js — the interface, two of the five rules, the context

        

      

    


    
    

      

        Behavioural
        
Observerjs/patterns/observer.js

        
A subject announces that something changed; any number of subscribers
           react. The subject never learns who they are.

        

          Where it runs
          
The driver's GPS. DriverLocationPublisher emits a fix about
             eleven times a second; five observers act on it, including the safety monitor.

        

        

          What it replaces
          
GPS code that directly calls the map, the ETA label, the logger and the
             push service — and breaks if any of them is removed.

        

        

          See it live
          
Book a ride, then untick EtaPanelObserver while the car is
             moving. The ETA freezes; the car keeps driving. That is the decoupling, visible.

        

      

      

        
observer.js — subject, observer, and the wiring

        

      

    


    
    

      

        Behavioural
        
Statejs/patterns/state.js

        
Each stage of the ride is its own class holding the behaviour that is
           legal at that stage. The ride delegates instead of deciding.

        

          Where it runs
          
The lifecycle panel. The label on the right of each row is the actual
             class the ride is holding at that moment.

        

        

          What it replaces
          
The same if (status === ...) ladder copy-pasted into
             cancel(), next(), canRate() and every other method.

        

        

          See it live
          
Cancel during Driver arriving — allowed, with a fee. Press
             Driver cancels and the ride moves to RematchingState instead of dying.
             Wait for Ride in progress and both buttons disable themselves, because
             InProgressState says so.

        

      

      

        
state.js — the state interface, two states, and the context

        

      

    


    
    

      

        Structural
        
Facadejs/patterns/facade.js

        
One simple door in front of a complicated building. The button says
           bookRide() and knows nothing about what happens behind it.

        

          Where it runs
          
The Book ride button. One call fans out to seven steps across the geo,
             matching, pricing, tracking and payment subsystems.

        

        

          What it replaces
          
A click handler that has to know all five subsystems and the
             correct order to call them in.

        

        

          See it live
          
Filter the console to FACADE and book. Two lines. Then clear the
             filter to see everything those two lines set in motion.

        

      

      

        
facade.js — the one method the interface calls

        

      

    


    
    

      

        Structural
        
Decoratorjs/patterns/decorator.js

        
Wrap an object in another with the same interface, adding one duty around
           the call. The caller cannot tell, and the wrapped object never changes.

        

          Where it runs
          
Every pricing rule. The facade hands the calculator
             regulated(rule) — the rule inside FairInputGuard and
             SurgeCapGuard. The receipt shows the chain.

        

        

          What it replaces
          
The legal cap copied into every strategy (one forgets, one fine), or an
             if ladder creeping back into FareCalculator.

        

        

          See it live
          
Pick Festival surge ×3. The rule asks for 3x; the receipt gains a
             green Surge capped at 2x line and the console prints a DECORATOR correction.

        

      

      

        
decorator.js — the base wrapper and the legal cap

        

      

    


    
    

      

        Creational · bonus
        
Singletonjs/core/dispatchLog.js

        
Exactly one instance, shared by everything. Ask for it a hundred
           times and you get the same object back every time.

        

          Where it runs
          
The dispatch console itself. Six pattern files write to it and the UI
             reads from it — they must all be pointing at one log.

        

        

          What it replaces
          
Each module quietly making its own log, so the console shows a fraction
             of what actually happened.

        

        

          See it live
          
Every line in the console is proof — six separate files wrote
             into one shared list.

        

      

      

        
dispatchLog.js — the instance guard
